# StateOmen

StateOmen: Real-time data processing and predictive analytics engine for dynamic system states.

With StateOmen, you get a lightweight tool that stays out of your way.

**What you get**

- StateOmen: Real-time data processing and
- predictive analytics engine for dynamic
- system states

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/StateOmen.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

StateOmen is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
